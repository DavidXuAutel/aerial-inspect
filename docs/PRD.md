# Aerial Inspect — 产品定义（v0.1）

## 一句话

给定任务区与目标类型（如「大桥」），无人机自主搜索、抵近，按测绘规范采集影像，并输出三维模型与质检报告。

## 用户故事

1. 操作员输入：「在该河段找到主桥，环绕拍摄并建模。」
2. 系统分解为：搜索区 → 语义检测抵近 → 环绕航迹 → 高清采集 → 离线重建。
3. 交付物：`mesh/` 或 `pointcloud.ply` + `report.json`（覆盖度、重叠率、空洞提示）。

## 与 WAM 的分工

| 层级 | 负责方 | 不负责 |
|------|--------|--------|
| **Aerial Inspect（本仓）** | 任务 FSM、Survey 航迹、采集规范、重建与质检 | 训练世界模型、改安全罩参数 |
| **WAM** | π 跟踪、三区安全罩、短程避障、可选 vgoal 检测引导 | 全局 BA、COLMAP、orbit 航线 |
| **aerial-vgoal-wam** | YOLO-World、TargetTracker、Qwen HTTP 客户端 | 飞行控制 |
| **Qwen（H100）** | 自然语言 → `visual_prompt` + `search_area` | 在线飞控 |

## 里程碑

| 阶段 | 目标 | 验收 |
|------|------|------|
| **M1** | 语义 SEARCH → 自动估计桥中心 → orbit 环绕 + Recorder 出图 | ≥1 条桥 200+ 张图，位姿 jsonl 完整 |
| **M2** | 区域搜索增强 + 覆盖度反馈补拍 | 环绕 ≥2 圈，航向重叠 ≥70% |
| **M3** | COLMAP 自动重建 + 质检报告 | 粗模可见桥面/主塔，报告含空洞区 |

## 非目标（v0.1）

- 不替代 WAM Phase-3 统一训练主线
- 不在 Orin 上跑 COLMAP / 3DGS
- 不承诺厘米级测绘精度（需 RTK 与标定另案）
